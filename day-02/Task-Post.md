🌟 Day 02 of #GCPZeroToHero series – GCP Project Setup & Billing ☁️💳

Setting up your Google Cloud environment & the organization/projects hierarchy correctly can save you time, cost, and improve efficiency down the road.

Day 02’s focus: laying the foundation for efficient, organized, and cost-aware GCP usage. 

💡 Here’s what is covered:
   • GCP Hierarchy - How resources are structured for better management.
   • Understanding Projects - A project is like your personal folder where all your cloud resources live, each with its own billing, permissions, and API settings, and you can have several of these folders under one billing account.
   • Billing Accounts - Linking projects, free tier usage, and when charges apply
   • Budget Alerts - Tracking costs to avoid surprises
   • Enabling APIs - Activating core services for your workloads

🛠️ Key Hands-On Steps:
    1. Create a New Project - Keep resources organized and billing clear.
    2. Set Budget Alerts - Example: ₹1000 limit with alerts at 50%, 90%, and 100%.
    3. Enable APIs - Compute Engine, Cloud Storage, Logging, Monitoring, Resource Manager, IAM credentials.

💬 Your GCP journey becomes smoother when you start with clarity, structure, and cost awareness.
